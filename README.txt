SOMYA SURPRISE WEBSITE — FREE STATIC SITE

Files:
- index.html: the complete responsive website.

Preview:
1. On a computer, double-click index.html to open it in a browser.
2. On Android, you can open it using a code editor/HTML preview app, or publish it using the steps below.

Publish free with GitHub Pages:
1. Sign in or create an account at https://github.com/
2. Create a new public repository named somya-surprise (or any name you like).
3. Upload index.html to the repository root using Add file > Upload files, then commit.
4. Open repository Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch; select main and /(root), then Save.
6. Wait a few minutes. GitHub Pages will show the public website address in Settings > Pages. It will usually look like https://YOUR-USERNAME.github.io/somya-surprise/
7. Open the link on your phone to test it, then send it to Somya.

Notes:
- GitHub Pages is free for public repositories, subject to GitHub's current terms and limits.
- The photo puzzle and song picker are browser-local: a photo/song selected by one visitor is not uploaded or shared with other visitors. The page itself is shareable, but each visitor would need to select a local photo/song. To show a fixed couple photo to Somya automatically, you would need to place a photo file in the repository and adjust the page to reference it; consider privacy before making a personal photo public.
- Don't upload private or intimate photos. Use images both people are comfortable sharing.
- This page does not collect or send personal data.
