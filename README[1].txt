Files:

- somya-photo.jpeg

To publish on GitHub Pages:
1. Open your repository: https://github.com/mayank-devp/Somya_Surprise
2. Upload/replace BOTH index.html and somya-photo.jpeg in the repository's main/root folder.
3. Commit the changes.
4. Wait a minute or two, then refresh https://mayank-devp.github.io/Somya_Surprise/

Important: the photo is included in the site files, so it appears automatically. Because GitHub Pages is public, anyone with access to the website may be able to see this photo. Only publish it if you are comfortable with that.
